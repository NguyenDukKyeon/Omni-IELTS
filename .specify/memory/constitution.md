# EWF Local Artifact Bridge

This bridge is not canonical authority and is not acceptance evidence. It only points local EWF artifacts to the repository sources that govern them.

- [`AGENTS.md`](../../AGENTS.md) — repository-wide working rules.
- [`docs/ROADMAP.md`](../../docs/ROADMAP.md) — canonical package sequencing and scope.
- [`docs/IMPLEMENTATION_PLAN.md`](../../docs/IMPLEMENTATION_PLAN.md) — canonical implementation commitments.
- [`docs/IMPLEMENTATION_STATUS.md`](../../docs/IMPLEMENTATION_STATUS.md) — canonical implementation state.
- [`docs/DECISIONS.md`](../../docs/DECISIONS.md) — canonical architecture decisions.

Those canonical sources take precedence over every `.specify/` artifact. If a local artifact conflicts with them, stop and obtain a corrected authorization before continuing.
