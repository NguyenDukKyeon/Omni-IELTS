## 7. Video / Media Experience Deep Dive

### 7.1 Orthogonal modes and optional orchestration

The six semantic media modes remain independent capabilities: Normal, Noticing, Shadowing, Strict Dictation, Practice Dictation, and Retell. The guided seven-step sequence is an optional orchestration across capabilities, not seven top-level destinations and not a global unlock chain. Learners may start, skip, change activity, or exit while a narrow in-activity integrity lock protects an active attempt. This is preserved by REC-REM002-010 and REC-REM002-018.

| Dimension | Preserved contract | Evidence consequence | Anchor |
|---|---|---|---|
| Stable workspace | source, active cue, player position/rate, transcript context, and relevant draft survive mode switches | context continuity is not itself learning evidence | REC-REM002-002, 010 |
| Strict Dictation | target text is absent from visible UI and DOM/ARIA before submit; single attempt truth retained | no exposed answer can enter positive independent evidence | REC-REM002-010, 016, 020 |
| Practice Dictation | replay, rate, first-letter/progressive hint, partial/full reveal, comparison, and retry may be offered and logged | coaching envelope marks assistance; no automatic FSRS update | REC-REM002-010, 020, 023 |
| Noticing | exact cue supports thought groups, weak forms, stress, chunks, IPA, reductions, phrases, collocations, and grammar through progressive disclosure | inspection/coaching only | REC-REM002-003, 010 |
| Shadowing | listen → repeat → record → replay/compare with rhythm/pronunciation support | coaching-only; never positive independent evidence | REC-REM002-013, 020, 028 |
| Retell | source comprehension → reduced transcript/cues → learner-generated oral/written reconstruction → feedback/retry | unassisted output still needs a verified evaluator and eligible receipt | REC-REM002-003, 013, 020, 023 |

Word Rearrangement remains rejected. Dictation target types remain Fill Gaps and Full Sentence. No research source changes that owner decision.

### 7.2 Seven-step session contract

The current sentence loop remains semantically intact under REC-REM002-003 and REC-REM002-010:

1. orient to source and exact cue;
2. attempt Strict or Practice Dictation with mode truth;
3. compare only after permitted reveal;
4. notice thought groups, weak forms, IPA, chunks, and connected speech;
5. shadow, self-record, and replay;
6. capture a word/collocation into the staged Inbox;
7. retell/reconstruct meaning with recoverable draft and evidence-honest evaluation.

Step order can be recommended, but the learner can enter or leave without a global route lock. A draft and immediate session audio can be protected during an in-progress activity; that local integrity mechanism is not a curriculum gate.

### 7.3 Cue continuity and failure states

The continuity tuple is source identity + source revision + cue/segment identity + real media start/end where aligned + transcript text/context + learner draft/attempt lineage. Language Reactor demonstrates that subtitle index, video identity, timestamps, images, and audio can coexist in a context-bearing record; this is vocabulary for research, not a selected schema. W3 implication is REC-REM002-002.

Required state variants for later W3 exploration are anchored rather than prescribed independently:

- progressive processing, first-safe-cue availability, cancellation, resume, and honest incomplete state — REC-REM002-022;
- missing captions, blocked/private source, unaligned cue, source revision, offline, and best-available context — REC-REM002-002;
- fixed audio controls that never cover mobile navigation or focused content — REC-REM002-025, 026;
- Desktop ASR Connected/Disconnected/Unavailable plus caption/import/manual alternatives — REC-REM002-022.

## 8. Vocabulary & Collocation Experience Deep Dive

### 8.1 Object and learning-goal model

One canonical lexical owner retains lemma/form, intended sense, collocations, register, source occurrences, active/passive goals, lifecycle status, and distinct skill evidence. The learner sees a coherent object rather than separate stores for Reader words, Video words, IELTS vocabulary, errors, or notes. This is KEEP under REC-REM002-005 and REC-REM002-006, and duplicate stores are REJECT under REC-REM002-024.

| Dimension | Preserved semantics | Prohibited compression |
|---|---|---|
| Sense and form | intended sense, inflection/morphology, pronunciation, and ambiguity confirmation | one dictionary gloss as full mastery |
| Collocation | multiword pattern, grammatical frame, register, and source example | bag-of-words association |
| Source lineage | all occurrences with source/revision/locator and privacy/rights truth | detached flashcard with no context |
| Goal | active vs passive and skill-specific target dimensions | one universal mastery bit |
| Lifecycle | new, learning, familiar, review, mastered, suspended, archived | visual hiding of suspended/archived cards |
| Evidence | recognition, recall, typing, listening, pronunciation, and productive use remain distinct | completion or exposure as proof |

### 8.2 Staged lifecycle

    SOURCE OCCURRENCE
      → STAGED CAPTURE
      → CONFIRM TERM / SENSE / COLLOCATION / SOURCE / GOAL / DUPLICATE
      → ONE LEXICAL OBJECT
      → MODEL / GUIDED PRACTICE AS NEEDED
      → QUALIFIED FSRS REVIEW BY SKILL
      → PRODUCTIVE USE
      → ERROR / REMEDIATION
      → CLEAN + DELAYED TRANSFER
      → RETURN TO ORIGINAL OR BEST-AVAILABLE CONTEXT

Capture never directly schedules a cold, ambiguous object. Discard offers Undo. Duplicate resolution merges source occurrences without silently merging incompatible senses. These implications are fully anchored by REC-REM002-006 and REC-REM002-021.

### 8.3 Evidence and agency safeguards

FSRS represents memory scheduling for qualified skill evidence. It is not mastery, IELTS ability, misconception certainty, or transfer. Assistance exposure remains inspectable and default-deny. Learners may choose direct vocabulary practice, source re-entry, or a recommended repair without navigation locks. These are KEEP records REC-REM002-007, REC-REM002-018, and REC-REM002-023.

### 9.5 Feedback as a teaching event

Feedback may verify, correct, explain, highlight evidence, show a contrast, use metalinguistic language, or offer a Socratic hint. The 28 REC-REM002 identifiers are intentionally preserved as stable recommendation identities from the frozen predecessor. REM-003 repairs their evidence bindings and confidence where required; it does not manufacture 28 apparently new prescriptions by renumbering unchanged passing work.

COGNITIVE_LOAD uses literal burden polarity:

- LOW = low avoidable burden, favorable;
- MEDIUM = moderate burden;
- HIGH = high/heavy burden.

The order of the score columns is TASK_FIT, INTERACTION_CLARITY, LEARNING_VALUE, COGNITIVE_LOAD, MOBILE_QUALITY, ACCESSIBILITY_SIGNAL, OMNIIELTS_FIT, and EVIDENCE_CONFIDENCE. There is no numerical pseudo-precision.
