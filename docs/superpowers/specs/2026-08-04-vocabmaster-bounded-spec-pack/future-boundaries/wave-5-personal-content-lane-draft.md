## Wave purpose

Turn a safe private source into validated, runnable learning activities and an
explicit refill workflow. This follows the useful manual-source vertical slice;
it does not require AI generation for the core path and cannot publish private
content or qualify evidence by itself.

## Boundary rules

- Original Source always creates an immutable Source Revision before extraction
  or compilation.
- AI-generated content is a draft until deterministic validators and required
  user/human approval pass; AI agreement is never approval.
- Compilation is deterministic for the same source/compiler version or returns
  an explicit quarantine/finding.
- Content defects remain separate from learner errors.
- The supply meter never changes Today priority or triggers a provider on open.
- Refill is explicit, cost/consent bounded and idempotent; provider failure loses
  no source or approved activity.
- “Full lane” is not full source-format or IELTS coverage.
